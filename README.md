# MI_unet_rate

Node **MI_unet_rate** (categoria `advanced/loaders`).

- Llista els models de `models/diffusion_models` (i `models/unet`).
- Fila de 3 estrelles sota el desplegable. Clic = valorar el model seleccionat; clic a l'última estrella activa = treu-ne una (la primera la deixa a 0).
- Les valoracions es desen a `ratings.json` dins la carpeta del node (persistents i compartides entre workflows).

## Instal·lació
Copia la carpeta `MI_unet_rate` a `ComfyUI/custom_nodes/` i reinicia ComfyUI.
- Sota les estrelles hi ha un camp d'**comments** (nota personal) d'una sola línia per model (clic per editar). Es desa a `notes.json`.
