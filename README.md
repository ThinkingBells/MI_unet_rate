# ComfyUI-UNET-Rating

Node **Load UNET (Rated ★)** (categoria `advanced/loaders`).

- Llista els models de `models/diffusion_models` (i `models/unet`).
- Fila de 5 estrelles sota el desplegable: clic = valorar el model seleccionat; clic a l'estrella ja activa = esborrar la valoració.
- Les valoracions es desen a `ratings.json` dins la carpeta del node (persistents i compartides entre workflows).

## Instal·lació
Copia la carpeta `ComfyUI-UNET-Rating` a `ComfyUI/custom_nodes/` i reinicia ComfyUI.
